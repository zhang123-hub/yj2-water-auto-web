# yj2-water-auto-web
河海大学网页设计大赛参赛作品
队伍：YJ²
成员：张庆元、顾杰、祝仕杰

## 项目主题
水利自动化监测平台动态网页
以智慧水库水位监测、闸门自动化调度为核心，页面搭载粒子动效，内置【守护水位】交互小游戏。
小游戏玩法：拖动泄洪闸门承接雨滴，控制水库水位维持在安全区间，模拟防汛调度自动化闭环。

## 技术栈
HTML + CSS + JavaScript，原生Canvas实现小游戏，无重型依赖

## 功能
- 水利自动化数据可视化面板
- 动态粒子背景
- 弹窗式小游戏「守护水位」
- 响应交互动画

## 使用方式
访问Github Pages链接直接浏览网页，点击YJ²队标打开小游戏。
